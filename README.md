# ChangeGuard AI

Monorepo for analyzing pull request impact, securing tool calls, and coordinating CI/CD strategies.

## Structure

- `agent/`: Python agent and PR analysis tool.
- `context/`: Python impact context server.
- `broker/`: Python secure tool-call broker.
- `cicd/`: Python CI/CD orchestration tools.
- `dashboard/`: Python dashboard application.
- `contracts/`: Shared JSON contracts.
